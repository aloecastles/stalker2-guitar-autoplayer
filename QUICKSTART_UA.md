# Інструкція: як запустити скрипт з нуля

Покрокова інструкція для тих, хто ніколи не працював з Python, git та командним рядком. Якщо щось уже встановлено - можна пропустити відповідний крок.

## Що тобі знадобиться

- Windows 10 або 11
- Куплений S.T.A.L.K.E.R. 2 з підібраною гітарою в грі
- 15-20 хвилин на перше налаштування

---

## Крок 1. Встановити Python

Python - це мова програмування, на якій написаний скрипт. Треба її поставити на ПК.

1. Зайди на https://www.python.org/downloads/
2. Натисни велику жовту кнопку **"Download Python 3.X.X"** (версія неважлива, головне 3.8 або новіша)
3. Запусти завантажений файл (`python-3.X.X-amd64.exe`)
4. **ВАЖЛИВО:** на першому екрані інсталятора постав галочку **"Add python.exe to PATH"** (внизу вікна). Без неї нічого не запрацює.
5. Натисни **"Install Now"**
6. Чекай 1-2 хвилини, поки встановиться
7. Натисни **"Close"**

### Перевірка
Натисни клавіші `Win + R` на клавіатурі. У вікні, що відкриється, введи `cmd` та натисни Enter. Відкриється чорне вікно (це командний рядок). Введи в ньому:

```
python --version
```

Натисни Enter. Якщо побачиш щось типу `Python 3.12.5` - все добре. Якщо побачиш помилку `'python' не є внутрішньою або зовнішньою командою` - Python не доданий до PATH. Перевстанови та постав галочку на кроці 4.

## Крок 2. Завантажити проект з GitHub

1. Зайди на сторінку репозиторію (посилання дай мені, або відкрий своє).
2. Натисни велику зелену кнопку **"Code"** у правому верхньому куті списку файлів.
3. Внизу меню, що випало, натисни **"Download ZIP"**.
4. Збережи файл у зручне місце - наприклад, на робочий стіл.
5. Розпакуй ZIP. Клік правою кнопкою → "Видобути все..." → "Видобути". З'явиться папка типу `stalker2-guitar-player-main`.
6. Запам'ятай, де ця папка лежить.

---

## Крок 3. Відкрити папку проекту в командному рядку

Це найважча частина для початківців. Найпростіший спосіб:

1. Відкрий розпаковану папку в Провіднику (там, де лежать `guitar_player.py`, `README.md` і т.д.)
2. У провіднику клацни мишкою на адресний рядок зверху (де написаний шлях до папки)
3. Виділи весь шлях та скопіюй його (`Ctrl+C`)
4. Натисни `Win + R`, введи `cmd`, Enter
5. У чорному вікні введи:
   ```
   cd 
   ```
   (з пробілом в кінці), потім зроби клік правою кнопкою у вікні - шлях вставиться. Натисни Enter.

Тепер командний рядок знаходиться "всередині" папки проекту. Це видно по тому, що на початку рядка тепер показано шлях до неї.

## Крок 4. Встановити залежності

У командному рядку, який зараз відкритий у папці проекту, введи:

```
pip install -r requirements.txt
```

Натисни Enter. Почнеться завантаження двох бібліотек - `pyautogui` та `pynput`. Чекай 30-60 секунд. Має закінчитись повідомленням типу `Successfully installed pyautogui-X.X pynput-X.X`.

### Якщо помилка
- `'pip' не є командою` - те саме, що з Python: PATH не додано. Перевстанови Python з галочкою.
- `ERROR: Could not find...` - перевір інтернет, спробуй ще раз.

## Крок 5. Налаштувати S.T.A.L.K.E.R. 2

1. Запусти гру
2. Зайди в `Налаштування → Графіка → Режим вікна`
3. Постав **Borderless** (вікно без рамки) замість **Fullscreen**
4. Збережи налаштування

Це треба тому, що в повноекранному режимі при Alt+Tab меню гітари закривається.

---

## Крок 6. Калібровка (один раз)

Скрипт повинен знати, де на твоєму екрані знаходяться сектори радіального меню. Це називається калібровкою. Робиться один раз, після цього не потрібно повторювати (поки не зміниш роздільність екрану).

### У грі:
1. Знайди табір з багаттям (на початку гри в Залісся це біля бараку Хом'яка)
2. Сядь до багаття - натисни клавішу "взаємодія", коли з'явиться напис "Sit"
3. Дістань гітару - натисни `TAB`, в радіальному меню вибери гітару (`G`)
4. Скіф сяде та триматиме гітару. У правій нижній частині екрану з'явиться радіальне меню з акордами (`C`, `G`, `Dm`, `Am`, `Em`, `F`)

### Перейди в командний рядок:
5. Натисни `Alt+Tab` (НЕ закриваючи меню гітари в грі)
6. У чорному вікні введи:
   ```
   python guitar_player.py calibrate
   ```
   Натисни Enter
7. Скрипт напише інструкції та попросить натиснути Enter
8. Натисни Enter

### Сама калібровка:
Скрипт по черзі попросить навести мишку на 6 секторів та натиснути `F8` для кожного. Порядок:

1. **TOP (зверху, 12 годин)** - там написано `C`. Наведи мишку точно на текст `C`, натисни `F8`
2. **TOP-RIGHT (праворуч-зверху, 2 години)** - там `G`. Наведи, `F8`
3. **BOTTOM-RIGHT (праворуч-знизу, 4 години)** - `Dm`. Наведи, `F8`
4. **BOTTOM (знизу, 6 годин)** - `Am`. Наведи, `F8`
5. **BOTTOM-LEFT (ліворуч-знизу, 8 годин)** - `Em`. Наведи, `F8`
6. **LEFT (ліворуч, 10 годин)** - `F`. Наведи, `F8`

Після останнього сектора з'явиться напис `Calibration complete`. У папці проекту з'явиться файл `guitar_config.json` - він зберігає координати, не видаляй його.

### Якщо помилився
Просто запусти команду калібровки знов - усі координати перепишуться.

---

## Крок 7. Запустити пісню

### У грі:
1. Зайди до табору, сядь, візьми гітару (як в попередньому кроці)
2. Переконайся, що меню гітари відкрите

### У командному рядку (через Alt+Tab):
3. Введи:
   ```
   python guitar_player.py play songs/twinkle.json
   ```
4. Натисни Enter
5. З'явиться зворотний відлік: `5... 4... 3... 2... 1...`
6. **Швидко натисни `Alt+Tab` назад у гру** до того, як відлік закінчиться

Скрипт почне рухати мишкою та натискати - має заграти "Twinkle Twinkle Little Star". Тривалість ~45 секунд.

### Як зупинити
Якщо щось пішло не так і треба терміново зупинити - **переведи курсор у верхній лівий кут екрану** (просто рукою смикни мишку максимально вліво-вгору). Скрипт зупиниться з помилкою.

## Часті проблеми

### Скрипт клікає, але не в ті місця
Перекалібруй (Крок 6). Можливо ти випадково навів не на той сектор, або змінилася роздільність екрану.

### Меню гітари закривається, як тільки запускається скрипт
Гра в повноекранному режимі. Перейди в Borderless (Крок 5).

### Гра не реагує на кліки скрипта
Деякі ігри ігнорують "штучні" натиски мишки. Спробуй запустити командний рядок від імені адміністратора:
1. Знайди cmd у меню Пуск
2. Клік правою → "Запуск від імені адміністратора"
3. Повтори кроки 3, 4, 6, 7

Якщо все одно не реагує - це проблема механіки гри, без модів її не обійти.

### `TAB` не перемикає скейл всередині пісні
У файлі `guitar_player.py` (відкрий звичайним блокнотом або Notepad++) знайди рядок:
```python
SCALE_SWAP_KEY = 'tab'
```
Заміни `tab` на ту клавішу, на яку у тебе насправді призначене перемикання скейлу в налаштуваннях гри. Наприклад, `'q'`, `'shift'` чи інша.

Для пісні `twinkle.json` це неважливо - там усі акорди в одному скейлі.

### Все працює, але звуки в грі грають з затримкою
Це затримка самої гри між кліком та звуком, скрипт тут не допоможе. Можна спробувати збільшити `duration` кожного акорду в JSON файлі - тоді ноти будуть звучати довше.

## Перевірка успіху

Якщо все запрацювало - спробуй другу пісню:

```
python guitar_player.py play songs/house_of_rising_sun.json
```

Вона використовує обидва скейли, тому ти побачиш, як скрипт натискає `TAB` для перемикання.
